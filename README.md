# PropostaFlow — MVP

Micro SaaS simples para criação e acompanhamento de propostas comerciais.

## Como abrir

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra o `index.html` com Live Server.

## O que já funciona

- Landing page
- Cadastro e login local
- Dashboard
- Cadastro e exclusão de clientes
- Criação de propostas
- Status: Rascunho, Aguardando, Aceita e Recusada
- Página pública da proposta
- Envio pelo WhatsApp
- Impressão / Salvar como PDF pelo navegador

## Importante

Nesta versão os dados ficam no `localStorage` do navegador. Isso é proposital para validar o produto primeiro.

Próximo passo recomendado:
- Supabase Auth
- Banco PostgreSQL no Supabase
- Segurança por usuário
- Link público real da proposta
- Cobrança com Mercado Pago ou Stripe
